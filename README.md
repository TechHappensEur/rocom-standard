# Rocom Standard — Robot-Enterprise Integration Protocol

> **DRAFT v0.1 — 2026-08-12**
> This specification is under active development. Not for production use.

Rocom is an open, vendor-neutral integration standard for robot fleet
orchestration in enterprise environments. It defines the protocol bindings,
capability profiles, and conformance requirements that enable heterogeneous
robot systems to interoperate with enterprise orchestration layers.
